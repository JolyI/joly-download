# Joly 下载 v1.4.0

本版更新清爽界面与 18 类文件图标，让文件信息、下载状态和操作更容易辨认。
下载管理功能沿用现有实现，无新增权限、运行时依赖或定时器。

## 更新内容

- 面板与设置页统一为灰白柔蓝主题，跟随系统切换亮暗模式，简化边框、阴影和装饰。
- 列表保持分行阅读：文件名与状态、来源与大小时间分别排布；当前任务用浅底色弱强调。
- 下载进度改为细横条，空状态使用下载线框图标，保留键盘焦点与减少动态效果支持。
- 文件图标统一为浅色圆角底与居中符号；图片与表格分别使用蓝色和绿色，适配列表内的 32 像素尺寸。
- 提供 PDF、Word、表格、演示文稿、纯文本、Markdown、代码、图片、矢量图、视频、音频、
  压缩包、磁盘镜像、安装包、字体、设计文件、电子书、其他文件共 18 类图标。
- 图标按扩展名识别，支持大小写与通用回退；原有列表分组、排序与下载操作规则保持一致。
- 扩展图标更新为透明底的 J 字母与下载箭头组合。
- 更新面板预览，新增图标预览与自动检查脚本。

## 安装与升级

需要 **Chrome 116 或更高版本**。

1. 下载本 Release 的 [`joly-download-v1.4.0.zip`](https://github.com/JolyI/joly-download/releases/download/v1.4.0/joly-download-v1.4.0.zip)，解压到准备长期保留的目录。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 点「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。

从旧版升级时，将新版本文件覆盖到原加载目录，再点击扩展卡片上的「重新加载」。
保持加载路径不变可沿用原扩展 ID 与设置；面板标题旁和设置页底部会显示 `v1.4.0`。

顶部「删除含文件」开关仍默认关闭：关闭时只移除记录，开启时连磁盘文件一起删除；
「清空」始终只移除记录。

## 开发检查与性能约定

仓库不需要安装运行时依赖。可运行：

```bash
node --check popup.js
node --check background.js
node --check options.js
node tools/check-file-icons.cjs
```

图标检查覆盖扩展名识别、大小写与通用回退、原分组兼容、同组改名以及进度更新时的节点复用。
`tools/preview.html`、`tools/preview-idle.html`、`tools/preview-empty.html` 和
`tools/preview-file-icons.html` 提供离线视觉预览。

继续遵循原有低内存约定：无 content script、无空闲轮询，进行中下载按需刷新，列表增量渲染，
面板关闭即销毁页面。打开空闲时低于 15 MB、有下载时低于 30 MB 仍是性能验收目标。
本次未重新实测进程内存；静态预览与脚本检查不覆盖真实下载、系统通知及文件操作的完整交互。
