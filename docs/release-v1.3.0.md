# Joly 下载 v1.3.0「国潮」

**UI 第四次改版。功能与 v1.2.0 完全一致 —— 零新增权限、零新增依赖、零新增定时器。**

## 这次改的是构图，不是配色

v1.1 刷颜色、v1.2 刷纹样，但骨架始终是「标题栏 + 标签栏 + 搜索栏 + 一条等权重的竖列表」，
所以看着还是旧。v1.3 换的是**构图与层级**：

| 位置 | 做法 |
|---|---|
| **顶栏** | 中国红实块 + 同心圆藻井，标题 900 字重 + 硬偏移阴影 |
| **可点元素** | 统一成「贴纸」：白底 + 2px 墨描边 + 2px 硬偏移阴影，按下时位移贴合阴影 |
| **主角卡** | 正在下载的那一件抬成大卡：大佛龛、30px 百分比、「下载中」角标 |
| **其余下载** | 压成单行贴纸：佛龛 + 文件名 + 进度 + 时刻 + 状态徽章 |
| **榜题** | 墨底金字标牌，件数是红底小印 |
| **佛龛** | 拱顶小龛，金箔从龛底涌起 —— 涌到的高度就是进度 |

配色：中国红（顶栏 / 危险 / 印章）、金（标题 / 贴金 / 榜题底）、石青（进行中 / 百分比 / 焦点环）、
石绿（已完成）、赭黄（已暂停 / 收尾中）。

## 主角卡的实现代价是零

主角卡**就是列表里的第一行，只多一个 `.is-hero` 类**。`pickHero()` 在渲染时挑出第一条
「还在跑」的下载（进行中 / 已暂停 / 安全扫描，被拦截的不算），`renderView()` 顺手 toggle。

**DOM 一个节点都没多**，更新路径与普通行完全一致 —— 没有新增定时器，没有新增内存驻留。

同一个 DOM 之所以能长出两副样子，靠 `display: contents` 把 `l1 / l2 / bar-row` 三层
摊平进 `.main` 再用 `order` 重排成单行；`.is-hero` 下把这些还原回块级。

## 性能（硬约束，未退化）

| 状态 | 内存 |
|---|---|
| 面板关闭 | ≈ 0 —— 零 content script，空闲零定时器 |
| 打开且空闲 | < 15 MB |
| 打开且有下载 | < 30 MB |

装饰全部走 CSS 伪元素与静态背景，唯一的动画是完成时的一次盖章。

## 安装

1. 下载本 Release 的 `joly-download-v1.3.0.zip` 并解压
2. 打开 `chrome://extensions`，右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择解压出的文件夹

需要 Chrome 116 及以上。

## 已知限制

- 空状态用的**飞天仍是占位图形**，等换上 iconfont 的正式稿
- 「删除含文件」是否绕过 macOS 废纸篓尚未实测确认
